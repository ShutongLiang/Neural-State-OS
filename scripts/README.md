# Research scripts

The public scripts cover activation capture, depth-band selection, writer and
reader packaging, paired response calibration, regularized attribution,
artifact verification, and scientific-figure rendering.

Historical filenames containing `direct6` indicate the original six-axis
prototype from which the generic tooling evolved. Passing a 44-axis dataset or
artifact bank activates the Direct-44 path; no six-axis writer is distributed.

Raw calibration text and full activation captures are intentionally absent.
Scripts that require them accept explicit input paths and refuse to overwrite
frozen artifacts by default.
